Tiny uppercase label/status marker — use for kit numbers context, match status, "NEW", "HOME/AWAY", etc.

```jsx
<Badge variant="gold">Home</Badge>
<Badge variant="success" subtle>Win</Badge>
```

Variants: `gold` (default), `navy`, `success`, `warning`, `danger`, `neutral`. `subtle` swaps the solid fill for a soft tint. Always renders UPPERCASE with wide tracking.
