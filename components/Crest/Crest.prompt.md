The dragon shield mark — the brand's strongest icon. Use as a badge, section divider, favicon, or faint watermark.

```jsx
<Crest size={48} />
<Crest watermark size={420} />     {/* faint background mark */}
```

`variant`: `2c` (navy+gold, default), `1c`, `k` (knockout/black). `watermark` dims to 6%. Override `src` if your asset path differs from `assets/logos/shield-*.svg`. Never redraw the crest by hand — always use this asset.
