Section header with eyebrow, title, gold rule, and optional description — the workhorse for page sections.

```jsx
<SectionHeading eyebrow="Join us" title="Come find your pack"
  description="All bodies, all levels — welcome here." />
<SectionHeading athletic align="center" title="Matchday" />
```

`athletic` swaps to loud all-caps GothamHTF. Default headings use the strong modern sans (Hanken Grotesk extrabold) — Harbour is reserved for the logo wordmark only, never headings. `align` left/center. `rule` toggles the gold underline.
